# jornada-ciber-2026
- encapsulamento nada mais é doq o processo de anexar informações de protocolo com informações de outro protocolo, em termos simples: é como dirigir um carro. Você sabe como acelerar, frear e virar o volante (interface pública), mas não precisa entender como a injeção eletrônica ou os pistões funcionam (detalhes encapsulados). Por que usamos o encapsulamento? Segurança: Impede que outras partes do sistema alterem dados de forma acidental ou maliciosa.Manutenção: Se você precisar mudar a forma como algo funciona por dentro, só precisa alterar o código da própria classe. O restante do sistema continua funcionando normalmente, entrew outras coisa
